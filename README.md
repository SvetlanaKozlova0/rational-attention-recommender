# Выпускная квалификационная работа
## Разработка методики построения рекомендательной подсистемы ленты публикаций на принципах рационального использования внимания пользователя

### Область и направление
**Область деятельности**: создание специального программного обеспечения электронных СМИ и компьютерных социальных сетей
**Направление деятельности**: совершенствование методического обеспечения процесса создания специального программного обеспечения электронных СМИ и компьютерных социальных сетей в части лент публикаций

### Актуальность
**Противоречие**: существует потребность в методах создания востребованных лент публикаций для СМИ и компьютерных социальных сетей, при этом современные компьютерные науки в их разработке не в полной мере учитывают достижения социальных и психологических наук

**Обеспечение разрешения противоречий** – возможности обусловлены следующими предпосылками:
- накоплен опыт эксплуатации лент публикаций;
- установлено влияние внимания на потребление информации;
- разработана концепция рационального потребления внимания пользователя ленты публикаций;
- сформирован теоретический задел в области компьютерных наук
  
**Требование разрешения противоречий**: необходимость обусловлена обострением конкурентных процессов организаций СМИ и социальных сетей

### Цель работы
**Как артефакт**: методика построения рекомендательной подсистемы для формирования ленты публикаций на принципах рационального использования внимания  
**Как эффект**: возможность создания лент публикаций, более востребованных у человека  
**Как процесс**: регламентация процессов создания специального программного обеспечения СМИ и компьютерных социальных сетей, а также его самонастройки в ходе эксплуатации  

### Задачи
- Сформировать описание процесса потребления публикаций из лент СМИ и компьютерных социальных сетей с оценкой качества и эффективности — как с учетом ресурса внимания, так и без него
- Разработать методику построения рекомендательной подсистемы ленты публикаций на принципах рационального использования внимания пользователя
- Экспериментально проверить адекватность методики через разработку прототипа СПО ленты публикаций
- Разработать рекомендации по внедрению методики

### Объект и предмет исследования
**Объектом исследования** являются процессы потребления публикаций из лент СМИ и компьютерных социальных сетей  
**Предметом исследования** является процесс формирования состава публикаций в ленте с учетом ресурса внимания

### Методы исследования и стек технологий
**Методы исследования**: системный и процессный анализ, методы поиска и анализа научной литературы, математическая статистика, методы социологии и психологии, методы проектирования программного обеспечения, имитационное моделирование, сравнительный анализ  
**Стек технологий**: Python и библиотеки для анализа данных (numpy, pandas), машинного обучения и метрик (scikit-learn), имитационного моделирования (Mesa), визуализации (matplotlib, seaborn), хранение данных (sqlite3). Среда выполнения: Jupyter Notebook / виртуальное окружение на локальном компьютере

### Практическая значимость
- Результаты работы могут быть использованы разработчиками компьютерных социальных сетей и электронных СМИ при проектировании рекомендательных подсистем, ориентированных на рациональное использование внимания пользователя
- Методика и критерии оценки могут быть использованы исследователями в области рекомендательных систем для дальнейшего развития подходов, учитывающих психологическое благополучие пользователя
- Предложенные критерии качества могут быть использованы для оценки этичности рекомендательных алгоритмов и формирования требований к платформам
